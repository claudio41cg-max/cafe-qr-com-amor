# Biblioteca de produtos ilustrativos

Este diretorio guarda **imagens demonstrativas reutilizaveis** de cafeterias brasileiras, separado do aplicativo e de cardapios de clientes.

- Imagens organizadas em `imagens/<categoria>/<produto>.webp`
- `catalogo.json` inclui o nome, categoria, descricao, preco nulo e caminho da imagem
- Cada cafeteria podera escolher itens sem modificar a biblioteca original
- Fotografia enviada por um cliente pertence ao cardapio daquele cliente, nao substitui a imagem mestre

## Importar primeiro pacote (30 produtos)

1. Baixe o arquivo `biblioteca_cafe_qr_30_para_github.zip` fornecido nesta conversa.
2. Na raiz deste repositorio, abra `biblioteca-produtos` e clique em **Add file > Upload files**.
3. Renomeie o ZIP para **pacote-imagens.zip** e envie-o para a pasta `biblioteca-produtos`.
4. O workflow **Importar biblioteca de imagens ilustrativas** extrai os arquivos, confere IDs e imagens identicas, e faz o commit automaticamente.

Os arquivos das imagens ainda **nao estao neste repositorio** ate a importacao terminar com sucesso.

O arquivo ZIP e somente um pacote de transferencia. As imagens extraidas constituem a biblioteca definitiva.
