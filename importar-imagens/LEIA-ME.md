# Envie o ZIP aqui

Abra esta pasta no GitHub e use **Add file > Upload files**. Envie **um único ZIP** com as imagens. A ação `Importar imagens de cafeteria por ZIP` extrai automaticamente os arquivos, guarda na biblioteca e atualiza as fotos dos produtos conhecidos do Café com Bolo.

Use nomes em minúsculas com hífens, exemplo: `pao-de-queijo.webp`, `banoffee.webp` e `cafe-coado.webp`. Pode conter até 300 imagens por lote. Imagens sem produto correspondente ficam guardadas na biblioteca para uso futuro. O QR e o painel no S20 não são alterados.
